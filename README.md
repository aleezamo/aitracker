# aitracker

aitracker is a lightweight JavaScript snippet that detects when users land on your website by clicking links cited in AI-generated responses (e.g., ChatGPT, AI search tools, etc.).

## Problem it solves
As AI tools increasingly cite external websites in their responses, developers have little visibility into when those citations actually drive user traffic.

Traditional analytics tools:
- Don’t clearly identify AI-generated referrals
- Don’t show which AI tools are sending users
- Make it hard to measure AI-driven engagement

## Solution
aitracker helps you track visits that originate from AI-cited links, giving you insight into how your content is being surfaced and used by AI tools.

## How to include the script

Add the following script tag inside the `<head>` of your HTML:

`<script src="https://your-domain.com/aitracker.js"></script>`

Once included, the script will automatically send tracking events when a user lands on your page via an AI-generated reference.
